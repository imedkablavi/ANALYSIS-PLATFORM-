# Network Behavioral Analysis & Suspicious Pattern Detection

**Ağ Tabanlı Şüpheli Davranış Örüntülerinin Analizi ve Multimedya Destekli Görselleştirilmesi**
MATLAB-first university research project (Çoklu Ortam).

A MATLAB analytical system that validates a real, anonymized co-offending dataset, builds
behavioural profiles, analyses temporal, spatial, network and sequence patterns, ranks unusual
record patterns with a transparent baseline and Isolation Forest, explains every ranking, and
presents the evidence in a linked, replayable multimedia application.

> **An anomaly score describes deviation from a statistical reference population. It is not a
> determination that a person committed, intends or is likely to commit a crime.**
> See [docs/ETHICS_AND_LIMITATIONS.md](docs/ETHICS_AND_LIMITATIONS.md).

## Pipeline

```text
Real artifact (pinned) → ingestion (ID restoration) → validation (37 checks)
 → canonical events · crimes · time-stamped relations
 → behavioural features (activity · temporal · spatial · co-offending · graph · sequence)
 → temporal series & change points · spatial grid & space-time excess · dynamic graph
 → pattern mining (recurring pairs/groups, n-grams)
 → anomaly detection (robust baseline + Isolation Forest, review budget)
 → explanations (deviation profile, exact baseline shares, occlusion attribution, text)
 → analysis bundle → experiments · figures · linked multimedia app (replay)
```

## Key data findings (verified)

- 17,237 offenders, 24,087 crimes, 34,156 offender–crime rows, 2010-12-01 … 2020-09-28 (day resolution).
- All 21,302 links are reciprocal (10,651 undirected ties) and every weight equals the number of
  shared crimes → the network is rebuilt from the records, with timestamps, as an undirected graph.
- 66 % of offenders have a single case; 3,260 have ≥ 3 and form the anomaly population.
- Pre-2014 data are sparse (91 rows) and recent months are right-censored (solved cases).

## Technology
