# Project Brief

## Proposed title

**Ağ Tabanlı Şüpheli Davranış Örüntülerinin Analizi ve Multimedya Destekli Görselleştirilmesi**

## English working title

**Network-Based Suspicious Behavior Pattern Analysis and Multimedia Visualization**

## One-sentence definition

A MATLAB-first analytical platform that ingests a real network/interaction dataset, constructs observable behavioral profiles, discovers temporal and relational patterns, detects anomalies, explains the evidence behind each alert, and presents the findings through an interactive multimedia interface.

## Why this is deeper than a simple network visualization

A simple visualization answers: “What does the network look like?”

This project aims to answer:

- What is normal for each entity?
- How does behavior change over time?
- Which interactions are unusually strong or newly emerging?
- Which sequences repeat?
- Which network structures are unusual?
- Why did the detector flag a specific observation?
- How can the user interactively replay and inspect the evidence?

## Core outputs

1. Cleaned and validated dataset
2. Feature matrix
3. Behavioral profiles
4. Network/graph model
5. Temporal and sequence representations
6. Anomaly scores
7. Discovered patterns
8. Explainability evidence
9. Interactive MATLAB application
10. Evaluation report
11. Reproducible experiment scripts
