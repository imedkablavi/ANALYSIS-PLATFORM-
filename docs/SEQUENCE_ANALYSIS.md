# Sequence Analysis

## Goal

Move beyond isolated events by analyzing order and recurrence.

## Candidate representations

- event bigrams/trigrams,
- entity-to-entity transition sequences,
- timestamped interaction chains,
- recurring subgraph transitions.

## Outputs

- top recurring sequences,
- rare sequences,
- sequence novelty score,
- timeline highlighting where a detected sequence appeared.

## Timebox

Do not implement a full research-grade sequential pattern mining framework. Implement one transparent method that can be explained during the defense.
