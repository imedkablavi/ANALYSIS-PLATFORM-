# Definition of Done

## Analytical feature
- [ ] Input/output documented
- [ ] Unit or verification test exists
- [ ] Uses real dataset fields
- [ ] No undocumented leakage
- [ ] Result reproducible

## ML experiment
- [ ] Dataset version recorded
- [ ] Feature version recorded
- [ ] Random seed recorded when applicable
- [ ] Threshold strategy documented
- [ ] Metrics generated
- [ ] Limitations recorded

## Multimedia feature
- [ ] User interaction works
- [ ] Visual state is understandable
- [ ] Reset/clear behavior works
- [ ] Does not hide analytical evidence
- [ ] Tested with a representative dataset slice

## Final release
- [ ] Clean clone test passed
- [ ] README updated
- [ ] Demo scenario verified
- [ ] Report figures regenerated from scripts
- [ ] No sensitive/raw unauthorized data committed
