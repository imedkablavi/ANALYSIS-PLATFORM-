# Definition of Done

## Analytical feature
- [ ] Input/output documented (docstring + docs/)
- [ ] Unit test on a synthetic fixture with hand-computed expectations
- [ ] Uses only verified dataset fields (registry `source` column)
- [ ] No look-ahead where time matters (causal baselines/states)
- [ ] **Executed in MATLAB** and result reproducible from `configs/projectConfig.m`

## ML experiment
- [ ] Dataset blob SHA, feature version, seed(s), settings recorded (`pipeline_run.json`)
- [ ] Threshold strategy documented (review budget)
- [ ] Metrics generated by `run_experiments.m`, not typed by hand
- [ ] Synthetic results labelled SYNTHETIC
- [ ] Limitations recorded

## Multimedia feature
- [ ] Interaction works in the app (verified by a person)
- [ ] Logic in a tested `src/` function; callback only wires it
- [ ] Reset/clear behaviour works
- [ ] Does not hide analytical evidence; no guilt wording
- [ ] Tested on the real dataset

## Final release
- [ ] Clean clone test passed on a second machine
- [ ] README updated
- [ ] Demo scenario verified
- [ ] Report figures regenerated from scripts
- [ ] No raw data or unauthorised identifiers committed
