# Multimedia Design

The dataset has no audio or video, so the multimedia contribution is the **synchronized,
time-based, interactive presentation** of analytical evidence: linked views, animation along the
time axis (replay), and an optional audio cue. Every visual element maps to an analytical output.

## Implementation decision

`app/NetworkBehaviorExplorer.m` is built programmatically from App Designer's component family
(`uifigure`, `uigridlayout`, `uiaxes`, `uitable`, `uislider`, `uitabgroup`, `timer`). Reasons:
a binary `.mlapp` is not diffable or reviewable in Git and cannot be authored without MATLAB; the
programmatic class uses the same components and can be ported into App Designer later.
Callbacks only call functions in `src/visualization/` and `src/`, which are tested without a GUI.

## Views (all linked)

| View | Content | Analytical source |
|---|---|---|
| Dashboard | counts, dates, validation status, eligible/flagged, agreement, unusual months, hotspots, patterns | bundle summary |
| Ranking table | flagged / top-200 IF / top-200 baseline / all eligible; ranks, scores, main group | `entities`, `explanations` |
| Network | 2-hop ego network; colour = score, size = crimes, width = shared crimes; click to select | `graph`, `plotEgoNetwork` |
| Timeline | monthly crimes, causal baseline, unusual months, change points, selected offender's crimes, playback cursor | `temporal`, `plotActivityTimeline` |
| Spatial | normalized density, current-window crimes, selected offender's numbered path | `spatial`, `plotSpatialView` |
| Why flagged | evidence text | `getEntityContext` |
| Deviation profile | robust-z bars by feature group with ±3.5 lines | `plotEvidenceBars` |
| Events | ordered crimes with token and surprisal | `events` |
| Partners | co-offenders, shared crimes, first/last date, their score; click to navigate | `relations` |
| Patterns | frequent/rare trigrams | `patterns.ngrams` |
| Detectors | baseline vs Isolation Forest scatter | `plotScoreComparison` |
| Data quality | validation checks | `validation` |

## Interaction model

- **Brushing and linking** (Becker & Cleveland 1987): one selection (table row, network node or
  partner row) drives network, timeline, map and all tabs.
- **Overview → zoom/filter → details on demand** (Shneiderman 1996): dashboard and ranking →
  ego network and time window → evidence and events.
- **Replay**: slider, Play/Pause, Step, Reset, window length (months). Each step recomputes the
  window with `buildPlaybackFrame`: ties appear at their first shared crime, the map shows the
  window's crimes, the timeline cursor moves, unusual months are labelled.

## Animation and audio principles

- Animation is used only for what actually changes over time (ties appearing, activity moving)
  and is user-controlled (pause/step/reset). Tversky, Morrison & Bétrancourt (2002) found little
  evidence that animation beats static graphics unless it is interactive and congruent with the
  content, so replay is an interactive tool, not an automatic effect.
- No decorative motion; one month per step at 0.8 s.
- Optional audio cue (short 880 Hz tone) when the replay enters an unusual month; off by default
  (`cfg.app.audio_cues`); every audio event also has a visual label, so nothing depends on sound.

## Export

"Export" writes PNGs of the network, timeline and map views and the entity's evidence text to
`outputs/`. Report figures are regenerated by `scripts/generate_report_figures.m` with the same
plotting functions.
