# Multimedia Design

## Purpose

The multimedia layer is not decoration. It is the interface through which analytical evidence is explored.

## Required interactive views

### 1. Dashboard

Summary counts, current anomaly level, selected time range, and model status.

### 2. Network view

Interactive graph with node/edge highlighting.

### 3. Timeline

Events and anomaly intervals aligned to time.

### 4. Heatmap / spatial view

Only when location data supports it.

### 5. Entity detail

Behavior profile, feature deviations, related entities, and event history.

### 6. Replay

Reconstruct an event window step by step using synchronized network/timeline views.

## Animation principles

- Use motion to communicate state/time changes.
- Do not animate constantly without analytical meaning.
- Provide pause/reset/step controls.
- Keep legends and labels visible.

## Optional audio

Audio feedback or short narration may be used for important application events, but it is optional. The analytical result must never depend on sound alone.
