# Graph / Network Analysis

## Graph model

Represent entities as nodes and interactions as edges.

Choose directed/undirected and weighted/unweighted semantics based on the source data.

## Metrics

Start small and justify each metric:

- degree / weighted degree,
- betweenness centrality,
- closeness centrality,
- connected components,
- community structure,
- edge persistence/change.

## Dynamic graph view

For temporal data, construct graph snapshots over fixed or event-driven windows and measure how node/edge relationships change.

## Visualization

The app should allow:

- zoom/pan,
- node selection,
- edge inspection,
- community filtering,
- time-window selection,
- highlighting anomalous nodes/edges.
