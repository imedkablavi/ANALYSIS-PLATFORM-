# ملفات التقييم والكشف والتحليل الزمني

هذا شرح للكود الموجود، وليس تقرير نتائج تشغيل MATLAB. لا توجد أرقام دقة مؤكدة قبل تشغيل التجارب على البيانات الفعلية والاحتفاظ بمخرجاتها. ملفات الاختبار تستخدم حالات صغيرة للتحقق من الحسابات؛ ليست بيانات عرض أو نتائج تجريبية للمشروع.

## مسار التشغيل الفعلي

- `configs/projectConfig.m`: معاملات التحليل والبذرة وميزانية المراجعة. الخيار `evaluation.include_synthetic=false` يعطّل حقن الانحرافات البحثي افتراضيًا.
- `scripts/run_experiments.m`: يقرأ حزمة تحليل محفوظة، ويشغّل التجارب على البيانات المحفوظة. المتغير `INCLUDE_SYNTHETIC=false` يبقي التقرير على البيانات المرصودة؛ تغييره إلى `true` طلب بحثي صريح.
- `scripts/verify_delivery.m`: ينفّذ الاختبارات وتحليل ملف شبكي ذي تسميات منشورة، ويتحقق من وجود نموذج Isolation Forest فعلي ونتائج تقييم قابلة للحساب. يفرض `include_synthetic=false`، حتى لو طلبت الإعدادات خلاف ذلك. يحفظ سجلًا وبصمات للملفات؛ فحص الواجهة يبقى يدويًا.

## `src/evaluation/`

| الملف | وظيفته وحدوده |
|---|---|
| `runExperiments.m` | يجمع فحوص الجودة وتوزيع الدرجات ومقارنة مجموعات الخصائص والثبات والتوقيت. يضيف التقييم بالتسميات المنشورة إن توفرت. لا يشغّل الحقن البحثي إلا بطلب صريح. |
| `evaluateGroundTruth.m` | يقارن الدرجات بتسميات الكيانات بعد انتهاء حسابها. يفصل الحالات ذات التسميات المعروفة عن افتراض اعتبار المجهول سلبيًا، ويبيّن عدد الكيانات الضارة المستبعدة بسبب قلة السجل. |
| `networkGroundTruth.m` | يحوّل تسميات التدفقات إلى تسميات مضيفين وفق دور المصدر أو الوجهة. وجود تدفق ضار موسوم عن المضيف يجعله موجبًا في هذا التقييم. |
| `rankAuc.m` | يحسب ROC-AUC من الرتب مع احتساب التعادل بنصف نقطة؛ يعيد NaN عند غياب إحدى الفئتين. يستخدمه التقييم بالتسميات المنشورة أيضًا. |
| `averagePrecision.m` | يحسب متوسط الدقة عبر عتبات الدرجات المميزة؛ تدخل الدرجات المتعادلة معًا حتى لا تتغير النتيجة بتغيير ترتيب الصفوف. |
| `precisionAtK.m` | يحسب الدقة والاسترجاع ضمن أعلى k درجات. التعادل يُحسم بترتيب الصفوف؛ يجب مراعاة ذلك عند تفسير النتائج. |
| `tiedRanks.m` | يعطي الرتبة المتوسطة للقيم المتعادلة، ويُستخدم في المقاييس الرتبية. |
| `spearmanRho.m` | يقارن ترتيب نموذجين باستخدام ارتباط سبيرمان. الاتفاق لا يعني صحة الكشف، والقيم غير الكافية أو الترتيب الثابت تعطي NaN. |
| `topKJaccard.m` | يقيس تقاطع أعلى k سجلًا مقسومًا على اتحادها، لمقارنة الثبات بين الإعدادات. |
| `injectSyntheticAnomalies.m` | أداة بحثية اختيارية تغيّر خصائص معيارية باتجاه الابتعاد عن المرجع وتعيد علامة الصفوف المعدّلة. لا تولّد هجمات فعلية ولا تسميات حقيقية، ولا تدخل المسار الافتراضي للتقرير أو التحقق. |
| `scoreSUS.m` | يحسب مقياس قابلية الاستخدام من استبيان ذي عشرة بنود مكتملة. الاستجابة الناقصة تعطي NaN؛ لا يصنع إجابات مشاركين. |
| `summarizeUsabilityLog.m` | يلخص نجاح المهام ومددها والمساعدة والأخطاء من سجل جلسات حقيقي يقدّمه الباحث. لا ينفّذ دراسة مستخدمين تلقائيًا. |
| `deliveryEvidence.m` | يحوّل الإعدادات إلى صيغة JSON آمنة، ويحفظ بصمات المصدر والمخرجات، ويتحقق من وجود نموذج فعلي. التشغيل المختصر أو الاختبارات المتجاوزة لا ينتجان حالة تحقق كاملة. |

عند عدم طلب الحقن البحثي لا تُكتب ملفاته ولا قسم نتائجه. تكون `synthetic_status` مساوية لـ `UNAVAILABLE_NOT_REQUESTED`؛ الجدول الفارغ يعني عدم وجود نتائج، وليس دقة تساوي صفرًا. عند طلبه، تُحفظ المخرجات داخل `research_synthetic/` بأسماء تبدأ بـ `synthetic_` ويُوسم قسمها بوضوح بأنه بحثي. يمكن لـ `opts.include_synthetic` تجاوز إعداد الحزمة صراحةً؛ التحقق من التسليم يمرّر `false` دائمًا. الملفات البحثية السابقة لا تُحذف تلقائيًا، ولذلك يجب عدم ضمها إلى عرض نتائج التشغيل الفعلي الجديد.

## شرح النتيجة: `src/explainability/explainAnomalies.m`

يستدعيه `runAnalysisPipeline` بعد تشغيل النموذجين. مدخلاته نتائج الشذوذ،
جدول الخصائص والإعدادات. يعيد بنية تضم جدول الملخص وجدول أدلة طويلًا مرتبطًا
برقم الكيان. يربط الانحرافات بقيم الخصائص ومرجعها، ويحسب حصص المرجع الإحصائي
وتأثير حجب الخصائص في Isolation Forest للكيانات التي شملها حد الشرح.
لا ينشئ تسميات هجوم ولا يحوّل الدرجة إلى احتمال إصابة.

تستخدم الحزمة هذه الأدلة في `entityEvidence` و`renderEntitySummary` وفي
التصدير. النص المعروض يُصاغ باللغة المختارة من القياسات المحفوظة؛ لا يُعاد
حساب الدرجة عند تغيير اللغة. غياب إسناد خاصية لا يُعرض على أنه تأثير صفري.

## `src/explainability/explainAnomalies.m`

- الدالة: `ex = explainAnomalies(res, features, cfg)`.
- المدخلات: نتيجة `runAnomalyDetection` وجدول خصائص الكيانات وإعدادات عدد التفسيرات وحد الانحراف. لا تستقبل تسميات هجوم لتكوين قصة تفسيرية.
- المخرجات: `ex.summary` لترتيب الكيانات ونص الدليل، و`ex.evidence` لقيمة كل خاصية ووسيط المرجع والانحراف والمساهمة، و`ex.groups` لتجميع المساهمات حسب مجموعة الخصائص.
- المستدعي الأساسي: `src/pipeline/runAnalysisPipeline.m` بعد حساب درجات الكشف؛ تُحفظ الجداول في حزمة التحليل والتصدير. تستخدم واجهة التفاصيل هذه القياسات، ويمكنها صياغة العرض بلغتها عبر `renderEntitySummary`.
- الحساب: مساهمة النموذج المرجعي من مربعات الانحراف؛ وعند وجود الغابة يُقاس تغير الدرجة عند استبدال خاصية أو مجموعة بوسيط المرجع. هذا تفسير حساسية للدرجة، وليس سببًا مثبتًا لسلوك الكيان أو إثبات هجوم.
