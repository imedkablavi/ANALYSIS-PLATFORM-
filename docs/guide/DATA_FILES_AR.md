# شرح ملفات البيانات والتحليل بالعربية

هذا الدليل يشرح الملفات الموجودة فعلًا في المجلدات المحددة أدناه، بحسب قراءة
الكود في النسخة الحالية بتاريخ 2026-11-01. وصف وظيفة الدالة لا يعني أنها شُغّلت
بنجاح على MATLAB. أسماء `crime` و`offender` في بعض الدوال موروثة من دراسة السطو؛
في استيراد الشبكات الحدث هو التدفق، والمشارك هو الجهاز، وليست هذه الأسماء حكمًا
على مستخدم الجهاز.

المسار المعتاد: ملف حقيقي → فحص البنية → استيراد وتوحيد → تحقق → أحداث وعلاقات
→ خصائص → تحليل وكشف → حزمة محفوظة. الواجهة تعرض الحزمة أو تستورد ملفًا يختاره
المستخدم. لا توجد في هذا المسار خطوة تولّد بيانات اختبار بديلة إذا غاب الملف.

| `inspectDatasetFile.m` | مسار → نوع الصيغة، profile، أسماء الأعمدة، خريطة حقول، وهل يحتاج المستخدم تعيين الأعمدة. | تستخدمه الواجهة و`analyzeDataset` والاستيراد. يختبر صيغة الشبكات المعروفة قبل اعتبار الملف قائمة روابط عامة؛ الصيغة غير المعروفة تبقى غير معروفة. |
| `labelNetworkFlows.m` | قاعدة الوسم وعمود الوسم وتفاصيله → class/role/detail وملاحظة تفسير. | يستخدمه مستورد التدفقات وفاحص الشرائح. CTU13: Botnet خبيث، Normal طبيعي، Background مجهول؛ To- يخص الوجهة. CIC وUNSW لهما قواعد منفصلة؛ لا تُستنتج وسمات من أسماء الملفات. |
| `loadBurglaryNetwork.m` | مسار NetworkX JSON → جدول عقد وروابط وعقد خام وخصائص المصدر. | يستدعيه استيراد JSON وسكربت فحص الدراسة القديمة. يتحقق من الحقول العليا ويُبقي مشكلات السجلات ليبلغ عنها التحقق لاحقًا. |
| `matchNetworkProfile.m` | مسار وأسماء أعمدة وprofile اختياري → profile وخريطة أعمدته وسبب الاختيار. | يستخدمه الاستيراد والفحص والمسح. يطابق عناوين مطبّعة؛ للصيغ بلا عنوان يفحص عدد الأعمدة ومحتوى أول السجلات، ويرفض الطلب القسري غير المطابق. |
| `networkFlowProfiles.m` | لا مدخلات → تعريفات CTU13 وCIC وUNSW وLANL. | يقرأها `matchNetworkProfile`. تحدد الترتيب/العناوين والوحدات وجمع أحجام الاتجاهين وقاعدة الوسوم وملاحظات مصدر البنية؛ ليست ملفات بيانات مضمّنة. |
| `parseTimeColumn.m` | عمود وقت ووحدة وصيغ نص اختيارية → datetime بلا منطقة زمنية وملاحظة تفسير. | يستخدمه الاستيراد والمسح. يدعم POSIX وExcel/datenum والتواريخ النصية؛ عند فشل قراءة مجموعة نصوص يجرب القيم منفردة، فيبقى التاريخ الفاسد NaT دون إفساد الباقي. الوحدات الرقمية الغامضة تحتاج تحديدًا. |
| `readDelimitedTable.m` | مسار وأعمدة يجب حفظها كنص → MATLAB table. | قارئ CSV/TSV/TXT العام في `importDataset`؛ يفوض اكتشاف التنسيق إلى `textImportOptions`. |
| `scanNetworkCapture.m` | ملف شبكة بعناوين وعدد صفوف للكتلة → جدول كتل بحدود الصفوف والوقت وعدد الوسوم. | يستدعيه `scripts/scan_capture.m` لاختيار شريحة معلنة من ملف كبير. هذا فحص وسوم للتقييم، لا تنفيذ كاشف ولا نتيجة دقة. |
| `textImportOptions.m` | مسار وأسماء أعمدة نصية → خيارات `detectImportOptions`. | تستخدمه قراءات النصوص. يتجاوز التعليقات البادئة بـ # في أول الملف فقط، ويحفظ المعرّفات كنص لتجنب فقد أرقامها أو قطع # داخلها. |
| `validateBurglaryNetwork.m` | البيانات الموحدة والأحداث والإعدادات → checks/errors/warnings/summary وحالة صلاحية. | يستخدمه خط التحليل وسكربت الفحص. الاسم تاريخي؛ يتعامل أيضًا مع الاستيراد العام ويعلّم فحوص الروابط/المكان غير المتاحة كغير منطبقة. يبلغ عن المشاكل ولا يختلق بدائل لها. |
| `verifyGitBlobSha.m` | مسار وبصمة متوقعة اختيارية → SHA-1 بصيغة Git blob ونتيجة المقارنة. | يستخدمه الاستيراد وسكربتات التنزيل والتحقق؛ يقرأ على دفعات لتجنب تحميل الملف كله في الذاكرة. البصمة تعرّف البايتات، ولا تثبت صحة التحليل. |
| `writeValidationReport.m` | تقرير التحقق ومجلد → مسارات ملفات JSON وCSV وMarkdown المكتوبة. | يستدعيه خط التحليل لحفظ العدادات والفحوص دون معرفات الأشخاص أو الأحداث. |

## فحص مسار العرض ومصادر الاختبار

`NetworkBehaviorExplorer` يقبل حزمة صريحة أو مسار حزمة، ويحاول الحزمة المحفوظة
المحددة عند التشغيل الافتراضي. إذا لم يجد حزمة صالحة يعرض حالة فارغة وخيار فتح
ملف؛ لا يستدعي `makeSyntheticNetworkJson` ولا يستورد `tests/fixtures` تلقائيًا.
`launch_app.m` يفتح هذه الواجهة؛ `run_network_demo.m` يطلب ملف CTU13 الحقيقي ويتحقق
منه. نتيجة ذلك: وجود fixtures داخل الاختبارات لا يجعل العرض الحالي وهميًا، لكنه
أيضًا لا يوفر نتيجة MATLAB إذا لم تُنتج الحزمة بعد.

توجد حقن اصطناعية مقصودة في `src/evaluation/runExperiments.m` لاختبارات E5–E7، مع
ملفات نتائج باسم `synthetic_...`. هذه تجارب منفصلة على الخصائص، ولا تستخدم لملء
واجهة بلا بيانات، ولا يجوز نسب نتائجها إلى الأوسمة المنشورة للمصدر.

عند فحص الملفات المحلية وُجدت عينات Stratosphere المنشورة `test2` و`test3` و`test5`
بجانب CTU13 الحقيقي. هي ملفات اختبار منشورة من الطرف الثالث، وليست صفوفًا اختلقها
المشروع؛ لكنها ليست السيناريو المعتمد للعرض، وبعض وسومها فارغة أو مختلفة. لذلك
أُبلغ المسؤول عنها للتنظيف دون حذفها ضمن مهمة كتابة هذا الدليل. التقرير المحلي
`outputs/reference/ctu13-scenario7.json` تدقيق Python مستقل، ويصرح بأن MATLAB والكاشف
لم يُشغّلا فيه. ملفات `.gitkeep` مجرد حافظات مجلدات وليست نتائج.

## توسيع الاستيراد لملف جديد

`src/data/validateImportOptions.m` يتحقق من صيغة الخيارات وأسماء الأعمدة ووحدات
التوقيت والحدود الصحيحة للصفوف قبل قراءة البيانات. يستعمله المسار والقارئ
مباشرة، فلا تعتمد سلامة الخيارات على نافذة التطبيق وحدها.

أضيف ملف تعريف `generic_network_flow` في `networkFlowProfiles.m` و
`matchNetworkProfile.m` للأعمدة العامة أو الربط الصريح. لا يختلق تسميات هجوم.
المخططات المعروفة تحتفظ بأولوية الكشف وقواعد وحداتها. المخطط العام لا يغير
قائمة علاقات بسيطة إلى مجموعة معلّمة دون دليل.
