# Final Demo Scenario

## Scenario

1. Open the MATLAB app.
2. Load the approved sample dataset.
3. Display global network statistics.
4. Select a time interval.
5. Display the dynamic network snapshot.
6. Run or load the validated anomaly model.
7. Highlight the top anomalous entity/event.
8. Open the entity detail panel.
9. Show the anomaly score and supporting evidence.
10. Move the timeline to the relevant interval.
11. Replay the sequence/network changes.
12. Switch to pattern view.
13. Export the analytical summary.

## Defense message

The demo should make one point clear: the system is not a static picture. It is a reproducible analytical pipeline whose result changes according to the input data and model settings.
